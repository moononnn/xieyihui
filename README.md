# 歇一会

> 温柔又执着的休息提醒助手。
> 到点后，你的助手会亲自接管屏幕，用尽一切办法让你休息。

---

## ⚠️ 用之前先知道这些

**它会盖住你的屏幕。** 到休息时间会弹出全屏窗口，普通模式可以点跳过

**它需要 Python。** 全屏窗口是独立的 PyQt6 进程，需要本机有 Python 3 和 PyQt6（`pip install pyqt6`）。没有 PyQt6 时插件会无法弹出窗口，建议先装好再启用。

**它会读你的最近对话。** 为了用当前助手的性格“劝”你休息，插件会在休息前读取当前助手最近几条公开会话，并通过该助手在 Hana 中已经配置好的文案模型生成回复。内容会发往你自己为 Hana 配置的模型服务；介意的话可以关闭“强制模式”或只当普通计时器用。



**它依赖 Hana 内部接口。** 助手识别、会话读取、模型调用走 Hana 的事件总线，Hana 大版本更新后可能需要适配。

**它会在你的数据目录里存东西。** 配置、成就和台词档案存在 Hana 的数据目录（`~/.hanako/data/xieyihui/`），卸载插件后如需彻底清理请一并删除。

---

## 它是干什么的


玩起电脑来就忘了时间，眼睛酸了也不肯停，说"再五分钟"结果又坐了半小时。所以需要一个强制提醒的助手！

普通模式基本就是一个简单的定时提醒你休息的小插件。

但是！！精髓在于强制模式！强制模式下就是小花劝休（息），小花（或者你的其他助手）会极力让你休息！

强制模式下不只是倒计时。它会在休息前按当前助手的性格和你们正在聊的事，提前准备好劝休息的话；你每点一次跳过，它都有回应，还会记仇——欠下的休息时间，下次一起还！

另外我做了“逃生窗口”，强制模式下使用逃生窗口可以直接跳过休息。但是我不准备直接说出来，如果你需要，可以把插件发给你的小花，让她帮你分析那个逃生窗口到底是怎么触发的。
但说真的，我不建议你知道！因为一旦知道有逃生窗口这个东西，强制模式的乐趣就少了很多。。。



## 它能做什么

⏰ **定时休息提醒** — 工作间隔可调（10 / 20 / 30 分钟或自定义，默认 30 分钟），到点弹出全屏休息窗口。

🌸 **当前助手亲自劝你** — 窗口显示当前助手的名字和头像，劝休息的话按她的性格和你们最近的对话实时生成。

💬 **实时回应** — 点击跳过必有文案回应，文案在休息前预生成好，点下去立刻就有反应，不用等模型。

🎭 **花招体系** —自己探索吧！

📒 **欠账机制** — 点跳过记 10 秒欠账，下次休息自动补还，窗口会明说"上次欠的 X 秒，这次一起还"。

🏆 **成就与称号** — 完成休息可点亮 14 枚成就，其中 4 枚会分阶段升级；设置页展示总休息时长 / 加时时长 / 斗智斗勇时长。

🧠 **文案会越用越活** — 模型生成过的台词会沉淀进本地档案，模型挂了也有三层兜底，永远不会没话说。

🤖 **自动跟随模型** — 每次生成文案都按当前助手和当前会话交给 Hana 解析模型配置。切换助手、增删助手或修改模型后，不需要在插件里重复设置。默认跟着当前助手的模型走就很好，想折腾的话也可以在设置页自己换个模型，选对了效果会更好哈。


## 安装

1. 下载插件包（zip）
2. 在 HanaAgent 中拖入 zip 安装，或在 Hana 插件目录（`~/.hanako/plugins/`）解压后启用
3. 确认本机有 Python 3 和 PyQt6：`pip install pyqt6`
4. 打开"歇一会"设置页，配置工作间隔和休息时长
5. 重启 Hana 生效

## 卸载

1. 在 Hana 插件管理里禁用/移除歇一会
2. 手动删除插件目录（`~/.hanako/plugins/xieyihui/`）
3. 如需彻底清理数据：删除 `~/.hanako/data/xieyihui/`（包含配置、成就和台词档案）

## 隐私提醒

- **对话内容**：插件读取当前助手最近的公开会话片段，并交给该助手在 Hana 中已配置的文案模型生成劝休息文案
- **模型密钥**：跟随助手和选择 Hana 模型时，插件不读取、不保存、也不回显模型 API Key，模型调用由 Hana 宿主管理；仅当使用自定义 API 模式时，插件才会把 Key 以**明文形式**保存在本地数据目录的 `model-config.json` 文件里（页面只显示脱敏占位符，留空保存不会覆盖，明确清除才删除）。它没有加密，同在这台电脑上的其他程序理论上能读到，介意的话别在公共电脑上开自定义 API 模式
- **网络权限**：默认情况（跟随助手 / 选择 Hana 模型）不发起任何网络请求；仅在自定义 API 模式下，插件才会直连你填写的 API 地址
- **头像**：每次打开休息窗口都会重新读取当前助手的本地头像；改名、换头像或切换助手后会自动更新，无头像时使用通用占位图案

## 兼容性

- 仅支持 Windows（全屏检测和系统通知走 Win32 API）
- Python 3 + PyQt6
- 依赖 Hana 事件总线：`agent:list`、`session:list`、`session:history`、`utility:call-text`
- 测试环境：HanaAgent Windows 版
